# 狀態頁（DIAG）怎麼讀

選單最後一格「狀態」。前鍵短按在「摘要」和「詳細」兩頁之間切換，前鍵長按 2 秒開啟 60 秒的新裝置配對（螢幕會顯示配對碼）。

## 摘要頁（給一般使用者）

大字結論：狀態良好 / 請留意 / 有問題。下面五行：

| 行 | 意思 |
|---|---|
| 電腦連線 | 已連上、沒連上 |
| 待傳筆記 | 還存在 Stick 裡、尚未傳到 Mac 的語音筆記數量 |
| 電量 | 百分比與充電中；剛開機或讀不到時顯示「量測中」 |
| 新裝置 | 已鎖定（不能配新裝置）或配對中 |
| 本機 | 穩定，或「曾自動重開」 |

「曾自動重開」時最下方會多一行重開機代碼，**先拍照再按前鍵**（離開詳細頁後記錄才清掉）。

## 重開機代碼

- `R50 C… M… H… L…`：監控偵測到某個工作停擺後自動重開。`M1` 顯示工作停擺，`M2` 按鍵，`M4` 錄音；`H` 是當時握著 LCD 鎖的工作（D 顯示、B 按鍵、R 錄音）；`C` 首位 5 表示卡在 LCD 的 SPI 傳輸；`L` 是最後一次畫的位置（1xxx 填色的列、3xxx 文字的橫座標）。
- `R4 <位址> E<n>`：程式崩潰。位址對回程式碼：

  ```
  . ../../esp-idf/export.sh
  xtensa-esp32s3-elf-addr2line -pfiaC -e build-menu/voxstick.elf <位址>
  ```

  要用刷進去的那一版編出來的 `voxstick.elf`。

## 詳細頁（英文縮寫）

LINK／PENDING／UPLOAD（上傳原因與次數）／BATT／READ（電池讀值是否可信）／HEAP／UP（開機秒數）／LCD WAIT（畫面鎖等待）／LAST RESET／QUIET（各工作最久沒回報）／PAIR（配對視窗）／SEC（配對安全計數，J 無安全連線、F 配對失敗、E 加密被拒，正常皆為 0）。

## 文字與字型

介面中文字使用 12 px 的 Fusion Pixel 繁中點陣字（OFL-1.1，見 `main/ZH_FONT_LICENSE.md`）。新增或修改任何中文字串後，要重跑產生器再編譯：

```
python3 tools/font/gen_zh_font.py <fusion-pixel-12px-monospaced-zh_tw.bdf>
```

中文最大放大 3 倍（`ZH_MAX_SCALE`），暫存區大小與它綁定。
